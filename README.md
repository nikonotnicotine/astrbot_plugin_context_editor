# AstrBot 可视化上下文编辑器

作者：[nikonotnicotine](https://github.com/nikonotnicotine)

这是一个用于查看、修改和清理 AstrBot LLM 对话上下文的插件。它在 AstrBot 插件页面中提供可视化面板，适合处理被提示词注入、错误工具结果、异常思维链或其他内容污染的对话记录。

## 功能

- 浏览全部平台和来源的 AstrBot 对话。
- 以卡片形式查看 `system`、`user`、`assistant` 和工具消息。
- 编辑消息内容、文本段及高级字段。
- 删除单条消息或独立内容段。
- 在历史末尾追加 `system`、`user` 或 `assistant` 消息。
- 识别并提示损坏或不符合 AstrBot Message 格式的记录。
- 使用版本校验防止覆盖刚产生的新消息。
- 可选保存前自动快照，并支持恢复最近 30 份快照。
- 可选在发送给 LLM 前过滤 `think` / `thinking` 思维链，减少无效 token 消耗。
- 玻璃质感中文界面，支持明确的悬停、点击和输入反馈。

## 思维链过滤

插件配置中的“是否将思维链发送给 LLM”默认关闭。

- 关闭：保持 AstrBot 原有行为，思维链会随上下文发送。
- 开启：只在构造 LLM 请求时过滤 `think` / `thinking`，数据库中的原始记录不会被修改。
- 开启后：可视化页面仍能查看思维链，但思维链显示为深色只读卡片，不能编辑内容。

过滤作用于请求副本，不会迁移或删除 AstrBot 数据库中的思维链。

## 自动快照

自动快照默认关闭。开启后，插件会在保存修改或恢复快照前备份当前上下文，并最多保留最近 30 份。关闭自动快照不会删除已有快照，已有快照仍可恢复。

## 安装

1. 将插件目录命名为 `astrbot_plugin_context_editor`。
2. 放入 AstrBot 的 `data/plugins/` 目录。
3. 重启 AstrBot。
4. 在 AstrBot WebUI 的插件页面中打开“可视化上下文”。

要求 AstrBot `>=4.24.2,<5`。

## 使用

1. 从左侧选择对话。
2. 点击消息右侧的“编辑”，修改允许编辑的内容。
3. 使用“删除”移除整条消息，或使用“删除此段”移除单个内容段。
4. 点击“保存修改”后，变更才会写入 AstrBot。

`ROLE` 与内容段 `TYPE` 对已有消息保持只读。损坏记录只能删除，内部 `_checkpoint` 记录也只能查看或删除。

## 安全设计

- 严格使用 AstrBot `Message` 模型校验保存内容。
- 已有消息不能修改角色或改变顺序。
- 新消息只能追加到上下文末尾。
- 保存时校验基础版本，避免覆盖并发更新。
- 思维链过滤仅修改本轮 `ProviderRequest.contexts`，不修改持久化历史。
